# Privacy

Luminique stores the language choice and video filter preferences in Chrome's local extension storage. Per-site settings are keyed by the website hostname so the extension can restore the user's choices on that site.

The extension source currently contains no analytics, advertising, account sign-in, or remote data collection endpoint. It does not send browsing history or video contents to a developer server.

Luminique's page access is used to identify videos, apply visual filters, and display the optional video control panel. Its storage and scripting permissions support these functions.

If the extension's data practices change, this notice should be updated before distribution.
